# Hobby-Matchmaker-for-Aatmoday
1. Project Overview
Hobby Matchmaker is a web-based platform designed to help people discover hobbies that match their interests, skills, personality, available time, and preferences.Existing platforms provide general hobby lists but do not offer personalized recommendations. The Hobby Matchmaker aims to provide a simple system that analyzes user preferences and matches them with suitable hobbies.
Main Objectives : Help users discover suitable hobbies.
                  Provide personalized hobby recommendations.
                  Save users' interests and preferences.
                  Allow users to explore different hobbies.
                  Provide information such as difficulty, time required, cost, and required materials. 
                  Encourage users to spend their free time productively.
                  Create an easy-to-use and attractive interface.
Key Features
👤 User Registration & Login
Users can create an account and securely log in.

📝 Hobby Preference Questionnaire
The system asks questions such as:
What are your interests?
Do you prefer indoor or outdoor activities?
How much free time do you have?
What is your budget?
Do you prefer individual or group activities?
What type of activities do you enjoy?

🎯 Personalized Matching
Based on the answers, the system calculates suitable hobbies and displays recommendations.

🔍 Hobby Search & Filter
Users can search hobbies and filter them according to:
Category
Cost
Difficulty
Indoor/Outdoor
Time required
Individual/Group

📚 Hobby Details
Each hobby can have:
Description
Benefits
Difficulty level
Required equipment
Estimated cost
Time required
Beginner tips

❤️ Favorites
Users can save hobbies they are interested in and view them later.

📊 Recommendation Score
The application can show a matching percentage.
Example:
🎨 Drawing — 92% Match
🎵 Music — 78% Match
📷 Photography — 71% Match

🛠️ Admin Panel
An administrator can:
Add new hobbies
Edit hobby information
Delete hobbies
Manage users
View basic system statistics

Tech Stack : Frontend: HTML, CSS, JavaScript
