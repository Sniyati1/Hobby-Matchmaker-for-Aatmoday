# Hobby-Matchmaker-for-Aatmoday
Hobby Matchmaker is a web-based platform designed to help people discover hobbies that match their interests, skills, personality, available time, and preferences.
Existing platforms provide general hobby lists but do not offer personalized recommendations. The Hobby Matchmaker aims to provide a simple system that analyzes user preferences and matches them with suitable hobbies.
Main Objective: provide personalized hobby recommendations, save users' interests and preferences, encourage users to spend their free time productively.
Features: 1) Hobby Preference Questionnarie
          2) Personalized Matching
          3) Hobby Search and filter
          4) Hobby Details
          5) Favorites
          6) Recommendation Score
          7) Admin Panel
Tech Stack: Frontend: HTML, CSS, JavaScript
            Backend: Python+Flask
            Database: MySQL
User Flow: Start -> Register/Login -> Enter Personal Preferences -> Answer Hobby Questionnaire -> Matching Algorithm -> Calculate Match Score -> Display Recommended Hobbies -> View Hobby Details -> Add to Favorites -> Explore Hobby
